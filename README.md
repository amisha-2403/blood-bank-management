# Blood Bank Management

A static blood bank management website template with pages for home, about, contact, login, and registration.

## Files

- `index.html` — home page
- `about.html` — about page
- `contact.html` — contact form
- `login.html` and `register.html` — demo authentication pages
- `css/` — stylesheets
- `js/` — browser-side scripts

## Run locally

Open `index.html` in a browser or serve the folder with a static HTTP server, for example `python -m http.server 8000`.

This is a front-end prototype. Authentication uses browser local storage and is not suitable for real accounts or sensitive donor data.
